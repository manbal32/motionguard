# 상담/분석 전환 수정

동의 미선택 시 서버가 거절한 뒤 입력 줄이 사라지던 흐름을, 전송 전 인라인 안내와 동의 포커스로 수정했다. 모델 응답이 비어 있으면 성공으로 기록하지 않는다. 전송 실패 시 입력 보존/재시도,35초 타임아웃으로 무한 대기 제한. 대화 이력은 매 턴 유지한다.

분석하기는 서버 요약 완료 전 즉시 요약 화면으로 이동한다. 준비/실패/재시도를 해당 화면에 표시하고 성공 전 승인 버튼을 비활성화한다. 이미지 이용 동의는 이 화면에 있으며 미동의로 이전 단계로 되돌리지 않는다. 기본 화면의 Gemini/대표사진 전송 기술 안내는 제거하고 데이터 안내와 짧은 이용 동의는 유지한다. 토큰 사용량은 기존대로 남긴다.

생성된 실제 instrument.js의 전송/요약 핸들러를 VM에서 실행해 다중턴 유지,동의 전 요청0회,요약 대기 중 화면 전환,실패 후 재시도 표시를 검증했다. Node48/실패0,빌드 및 JS문법 통과. 브라우저 모바일/실제 Gemini 추가 호출 검증은 지원 QA 도구 부재로 미완료. 서버 최근 오류 로그에는 상담 API 실패가 없어 사용자가 겪은 실제 네트워크 원인까지 확정하지 않았다.
