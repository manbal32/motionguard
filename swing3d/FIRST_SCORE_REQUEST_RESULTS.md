# 저장된 결과가 없는 첫 스코어 요청 복구

사용자 화면에서 v94의 날씨 오류가 반복됐다. v94는 이전 Gemini 결과를 다시 표시할 수 있게 했지만, 결과가 한 번도 없는 첫 요청은 브라우저의 날씨 조회 실패에서 계속 중단됐다. 이번 변경은 그 선조회 자체를 제거한다.

새 클라이언트는 분석/승인 요약과 선택18홀을 예측 API에 한 번 보낸다. 서버가 등록 골프장의 예보를 확인해 Gemini에 전달한다. 조회 실패 시 best-effort 요청은 weatherStatus=unavailable이라는 사실을 모델에 전달하고 날씨 미반영 기본조건의 실제 Gemini 예상을 받는다. 반환 점수/합계 검증은 유지하고 앱이 숫자나 날씨를 만들지 않는다. 기존 엄격 요청은 종전처럼503을 반환한다. 골프장 불일치/잘못된 요청은 거부한다.

결과에는 반영 상태와 명시적 안내를 둔다. 기본조건 결과에 바람 반영을 표시하지 않고, 자동 재생도 날씨를 다시 기다리거나 바람을 임의로 넣지 않는다. 사용자가 날씨를 다시 확인하면 서버 재예측을 요청한다. 모델429·형식/연결 실패는 성공으로 포장하지 않는다.

분석/승인 내용·선택18홀·시간 구간에 묶인 요청 캐시와 중복 요청 합치기를 유지한다. 예보반영은 최대10분, 미반영은30초 캐시로 복구 시 재확인 기회를 둔다. 원래 예보 스냅샷/이전 결과 저장 키도 유지하며, 강제 갱신은 캐시를 건너뛰되 진행 중 동일 요청은 합친다.
