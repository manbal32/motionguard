# 사진 코칭 다시보기: 동일 JPEG 기준과 비율 제한

사용자가 이전 수정 후에도 장면 불일치/2D공백/너무큰그림을재보고했다. 이전수정은기존국면·계측화면의캔버스경로를보완했지만사진코칭결과에서그화면으로진입하는구조가남아있었다.

이번에는사진코칭renderResult의실제show-points버튼을photo-replay.js에연결한다. local_stills선택객체하나(id/time/image)가원본사진과2D의공통기준이다. 둘다동일JPEG를즉시표시하고해당JPEG의IMAGE자세결과만현재2D로쓴다. 이전장면의느린추론은세대번호로차단한다. 현재2D가미준비/실패면동일사진과연습설명SVG를표시한다. 이설명SVG는개인교정완료모습이아니다.

원본반복은선택시점앞0.4초/뒤0.6초구간이며해당영상프레임좌표만표시에사용한다. 메타데이터후seek. 2D전환/종료가play대기중발생하면재생하지않는다. 같은URL로원본등록을갱신할때좌표frames도갱신해초기메타정보만남는경로를보완한다.
