# 원클릭 분석과 오류 회귀 수정

최근 서버 로그에서 상담/요약200, visual 요청 없음 확인. 토큰 소진으로 확정할 증거 없음. 기기내 추출/저장/프레임 단계의 사용자 실제 예외는 서버 로그에 없으므로 정확한 원인 미확정.

모션가드 코치 명칭 반영,요약은 개선/목표 제안을 채우고 직접 진술 없는 가설은 [코치 제안] 표기. 분석하기→내부요약→분석→결과 연결. 기존 이대로 분석 화면 미노출. 영상분석180초 제한과 abort race로 대기 제한,실패는 진행화면에 재시도/대화로 돌아가기 제공. 자동 과거 화면 회귀 제거. 모델 호출 실패를 가짜 결과로 대체하지 않음.

Node50개/실패0: 실제 생성 핸들러에서 추가 승인 없이 분석 호출,요약실패시 진행화면 유지/재시도 노출,로컬 무응답 abort종료 검증. 빌드/JS문법 통과. 실제 모바일 영상 업로드 E2E는 미검증,사용자에게 해결 확정으로 보고하지 않는다. 개인 영상/상담 원문 미커밋.
