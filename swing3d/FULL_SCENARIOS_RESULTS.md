# 전체 시연 통합 실측 (2026-11-20)

PR12, base feature/swing3d. 기존 영상/LLM 흐름에 자동 지도 후보와 현재·개선 후 비교를 연결했다. 실제 모바일 E2E와 모든 코스 자동화는 미통과다.

## 이용 흐름

홈 → 영상 업로드 → Gemini 상담 → 수정/승인 요약 → 로컬 좌표 추출·대표사진5장 → 별도 사진 동의 → Gemini 피드백·실제 토큰 → 반복 영상/정지2D → 피드백별 유튜브 → 골프장 검색 → 네이버 공개 지도 후보 분류 → 원본 이미지 홀 추론 → 현재/개선 후 샷·퍼팅 재생 → 분석 및 비교 PDF.

영상 없는 course.html?demo=1은 개인 측정0개와 명시적 가상 개선 후보3개로 시작한다. 이전 실제 사진 분석 측정값을 데모의 개인 측정으로 둔갑시키지 않는다.

Gemini 모델 gemini-3.5-flash-lite의 실제 지도 응답을 측정했다. 첫 보수적 호출은0홀, 상위 flash-latest 시험은45초 제한으로 실패했다. 좌표계0–1000 명시 및 낮은 신뢰도 후보 허용 후 위 결과를 얻었다. 실측 토큰은 성공 호출 기준이며 실패 호출 청구량은 미확인이다. 분류 경로는 mock 회귀 검증했고, 알려진 두 출처는 재분류를 건너뛰되 매번 새 원본 지도 추론을 한다.

## 모델과 데이터 제한

수준80/90/100/110의 캐리·편차·미스·퍼팅 확률은 설명 가능한 가정이다. 실제 과거 라운드 데이터로 학습/보정하지 않았다. Gemini의 평가 가능하고 낮은 신뢰도가 아닌 개선 후보 최대3개에 대해 후보당 편차8% 감소 등 가정을 적용한다. 실측 개선 효과가 아니며 OB/워터 벌타는 계산하지 않는다. 같은 seed/홀/조건으로 비교하며 타수를 목표값에 맞추지 않는다. 한 아이언 영상으로 전 클럽의 실제 탄도를 알 수 있다고 주장하지 않는다.

공개 검색 이미지 후보를 HTTPS 허용 CDN에서 크기/MIME/시간 제한으로 가져온다. 지도 여부·골프장·그룹·번호·경로를 검사하며 실패하면 기존 선택을 유지한다. 로그인/비공개 자료를 우회하지 않는다. 원본 지도는 회전·확대만 하며 모델의 미검증 경로임을 표시한다. 수집 가능성과 이미지 재사용 권리는 별개다. NAVER 지도 타일 캡처나 범용 완전 자동화 완료가 아니다.

공개 Git에는 출처 메타데이터·코드·테스트만 넣는다. 개인 원본 영상/좌표/실제 응답/출력 PDF/연구 이미지·API키는 제외한다. PDF는 현재 렌더러와 로컬 fixture의 실제 출력이며 모바일에서 직접 내보낸 결과는 아니다.

## 재현

```sh
cd swing3d/hosted
python scripts/build_server.py
node --test tests/*.test.mjs
node --input-type=module --check < dist/server/index.js
```

GEMINI_API_KEY는 서버 환경 비밀값이다. 지도 API: /api/courses/discover, /select-maps, /analyze-map, /image. 임의 원격 URL 프록시는 금지한다. course.html?demo=1에서 기본9홀,수준선택,개선후전환,재생/정지/다음홀,비교PDF를 시연한다. 지원하지 못한 지도는 실패 메시지를 확인한다.
