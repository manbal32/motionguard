# 이미지 중심 분석과 작은 골퍼 — 2026-11-20

최신 사용자 요청을 반영했다. 분석이 본체이고 가상 코스는 재미있는 보조 체험이다. 기존 상담/요약 승인/원본 계측/2D·3D/영상 저장/연습 링크/프로필 기능을 유지한다. 스윙 계측값·판정 기준·점수는 변경하지 않았다.

## 화면

- 결과 상단은 실제 분석 점수/국면, **잘한 점 1개 + 개선점 3개**의 이미지 카드로 구성. 근거 있는 긍정만 표시하고, 잘한 동작은 교정/변형하지 않는다.
- 각 카드에 현재 동작과 교정 방향 그림, 문제 부위 표시, 관찰·이해·연습 설명. 카드 내부의 0.5배 구간 반복/멈춤, 부위 확대/전체 자세 전환, 기존 교정 화면으로 연결.
- 이미지는 해당 분석의 **22점 계측 좌표**로 재구성한다. 원본 사진이라고 주장하지 않는다. 교정 그림은 교육용이며 측정 결과와 분리한다. 뒤꿈치처럼 고정 앵커를 유지해야 하는 항목은 임의로 발을 움직이지 않고 방향 화살표로 표시한다.
- 기준 자세 투영은 기존 `instrument.js`의 함수와 동일하게 `pose-project.js`로 추출해 공유. 기존 각도/스탠스 제한을 바꾸지 않았다.
- 타수 가정과 수치표는 접힌 참고 자료로 이동. 코스 총점은 결과/리포트의 대표 문구에서 제외.
- 코스는 승인된 원본 홀 지도와 초록 PLAY 디자인 유지. 작은 골퍼가 준비→백스윙→다운스윙/임팩트→공 비행→착지점까지 이동. 캐릭터는 사용자 스윙 복원이 아닌 연출.

## PDF

기본은 분석 이미지 중심 **5페이지**: 분석 요약, 잘한 점/개선점의 현재·가이드 이미지, 연습·측정 근거, 전체 수치 부록. 기본 PDF 텍스트에서 코스명과 타수 가정이 출력되지 않음을 확인했다. 사용자가 **‘가상 코스 기록도 PDF에 포함’**을 체크할 때만 동일 시나리오의 코스 기록을 더해 **9페이지**가 된다. 이전 7페이지 코스 중심 PDF는 이전 요청의 산출물이며 현재 기본 출력이 아니다.

## 재현/증거

```sh
node tests/visual_analysis_browser.cjs
VISUAL_TEST_URL=http://127.0.0.1:8895/motionguard/ node tests/visual_analysis_browser.cjs
python -m pytest -q
node --test tests/test_course_core.cjs tests/test_course_pdf.cjs tests/test_browser_core.cjs tests/test_comparison.cjs
```

`mockups/analysis-*.txt/json`, `mockups/shots/analysis_*`, `golfer_*`, `analysis-report.pdf`, `analysis-with-course.pdf`에 화면과 출력 보관.

내보내기 도구 `tools/build_visual_preview.py`는 **공개 샘플만** 사용한다. 원본 개인 영상/대화/키는 내보내지 않는다. 기본 PDF의 코스 기록 미포함, 지도 사용권/최신성 미확인, 네이버 자동화 미구현, 추정 비거리 모델 미검증은 유지한다. 앞선 단계 11 미통과를 해결했다고 주장하지 않는다. 외부 LLM 전송 범위/동의는 바꾸지 않았다.
