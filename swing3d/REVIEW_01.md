## 1 · 과장이 부호를 뒤집는다 (치명)

`shot_compare.png` 수치 줄 — 측정 `14.2°` / 교본 `44.0°` / 과장 표시 `-15.6°`.

계산 자체는 공식대로다. `44.0 + (14.2 - 44.0) × 2.0 = -15.6`.
**그런데 결과가 거짓말이다.** 백스윙 탑에서 몸통 회전이 음수면 **반대 방향으로 돌았다**
는 뜻이다. 사용자는 "덜 돌았다" 는 지적을 받아야 하는데 화면은 "거꾸로 돌았다" 를
보여준다. 과장이 아니라 날조다.

이것은 내 지시서의 구멍이다. 차이 증폭은 맞지만 **0 을 가로지르는 것을 막지 않았다.**

**규칙** — 과장은 **정도를 키우지 방향을 바꾸지 않는다.**
과장값은 측정값의 부호를 절대 뒤집지 않는다.

하드 클리핑하지 마라. 슬라이더가 중간에서 먹통이 된다. **0 에 점근하도록 압축한다.**

```js
const extra = (measured - referenceValue) * (factor - 1) * envelope;
const headroom = Math.abs(measured);          // 부호를 안 넘기려면 이만큼만
const limited = Math.abs(extra) <= headroom
  ? extra
  : Math.sign(extra) * headroom * (1 - Math.exp(-Math.abs(extra) / headroom));
displayed[measuredIndex] = measured + limited;
```

검산 — 측정 14.2 · 교본 44.0 · 배율 2.0 이면
`extra = -29.8`, `headroom = 14.2`, `|extra| > headroom` 이므로
`limited = -14.2 × (1 - e^(-2.098)) = -12.47` → 과장 표시 **`1.7°`**.

0 을 넘지 않으면서 "거의 안 돌았다" 를 보여준다. 배율을 3.0 으로 올려도 0 에
가까워질 뿐 음수가 되지 않는다.

`measured` 가 0 에 매우 가까우면 `headroom` 이 0 에 수렴해 과장이 사라진다.
그때는 `headroom = Math.max(Math.abs(measured), 2)` 로 최소 여유 2 단위를 준다.

`shiftX` · `heelR` 은 각도가 아니라 정규화 거리다. 최소 여유는 `0.02` 를 쓴다.

**완료 기준** — 9채널 전 프레임 배율 1.0–3.0 전 구간에서
`sign(과장값) === sign(측정값) || 측정값 === 0`. 위반 건수를 출력해 보고하라. 0 이어야 한다.

## 2 · 왼쪽에 측정 좌표가 없다

`shot_compare.png` 왼쪽은 그냥 영상이다. 관절이 하나도 안 찍혀 있다.
**이 화면의 전부가 "이게 내 스윙이다" 인데 그 증거가 빠졌다.**

- `관절 표시` 버튼의 기본값을 **켜짐**으로 바꾼다.
- 스크린샷은 관절이 보이는 상태로 찍는다.
- 교본 겹치기도 켜진 상태인데 회색 선이 안 보인다. 왼쪽 캔버스에도 그려지는지 확인하라.
  오른쪽에만 그려지고 있다면 그것이 버그다.

---

## 3 · 오른쪽 뼈대가 사람 형태가 아니다

다리가 셋처럼 보이고 팔이 꺾여 있다. 왼쪽 실제 자세와 같은 사람으로 보이지 않는다.
**과장 이전에 기본 뼈대 그리기가 틀렸다.**

진단 순서를 지켜라. 원인을 추측하지 말고 분리해서 확인하라.

1. **배율 1.0 으로 놓고** 오른쪽 뼈대를 왼쪽 관절 위치와 비교한다.
   1.0 에서 이미 형태가 다르면 과장 문제가 아니라 **좌표 → 뼈대 변환 문제**다.
2. 1.0 에서 맞으면 2.0 에서 어느 뼈가 깨지는지 채널을 하나씩 꺼가며 좁힌다.
3. 좌우 다리가 겹쳐 보이는 것인지, 뼈 연결이 잘못된 것인지 확인하라.
   `BONES` 연결 목록을 출력해 보고하라.

오른쪽 캔버스는 왼쪽과 **같은 원점 · 같은 스케일**을 써야 한다.
두 캔버스의 골반 중심 화면 좌표를 출력해 보고하라. 같아야 한다.

## 4 · 작은 것들

- **측정값 불일치** — 판정 카드는 `14.1°`, 수치 줄은 `14.2°`. 같은 프레임인데 다르다.
  어느 쪽이 트랙의 실제 값인지 확인하고 하나로 맞춰라. 반올림 시점이 다를 것이다.
- **판정 카드 줄바꿈 깨짐** — `측정 14.1° · 교본 44.0°` 가 줄바꿈되며 가운뎃점이
  행 머리에 떨어진다. 카드 폭을 늘리거나 두 값을 각각 한 줄로 두 줄 배치하라.
- **국면 눈금 겹침** — `다운스윙` 과 `임팩트` 가 겹쳐 뭉개진다.
  `golf1` 은 down 163 / impact 164 로 1프레임 차이다. 눈금 라벨이 겹칠 때는
  아래위로 번갈아 배치하고, 그래도 겹치면 뒤의 것만 남겨라.
- **인물 확대가 꺼져 있다** — 골퍼가 작게 나온다. 기본값을 켜짐으로 바꿔라.
  배경에 누운 사람이 하나 더 있다. MediaPipe 가 골퍼를 잡았는지,
  바운딩 박스가 두 사람을 다 감싸고 있지는 않은지 확인하라.
