# 쉬운 퍼팅 및 클럽별 거리

- 사용자 요청: 방향을 맞춘 퍼팅은 쉽게 들어가도록 한다. 클럽별 비거리 설정도 설명한다.
- 그린(14m 이내), 퍼터, 목표 방향±8°, 강수 반영 거리≥남은 거리50%이면 힘을 넉넉하게 보정해 홀인. 너무 약한 탭/잘못된 방향/그린 밖은 자동 보정하지 않는다.
- 사용자 퍼팅 입력과 애니메이션 완료 후1타 기록. 조준선은 보정 도착점, 샷 거리는 실제 굴러간 거리. 복구/되돌리기 유지.
- 퍼팅 도움말과 펼침형 클럽 거리 안내 추가. 거리 안내를 게임 엔진 상수에서 생성해 별도 표와 어긋나지 않게 함.
- 기준: 힘100%·기본 날씨. 드라이버220m,5번우드185m,유틸리티170m,5번아이언155m,7번아이언135m,9번아이언115m,PW90m,SW60m,퍼터20m. 개인 스윙 측정치가 아닌 게임 설정. 힘/날씨/비퍼터 작은 편차를 반영함.
- Node165/165: 다양한 그린 거리·방향·힘·비/바람 조건 보정, 잘못된 입력 조건 비보정, 조준/기록/1타/저장/되돌리기, 실제 안내 값 일치, 기존18홀 완주 및 전체 앱 회귀.
- 서비스의 분석 후 최종 시뮬레이션과 별도 테스트 `/play`가 동일한 변경을 공유함. 첫 화면 게임 진입은 추가하지 않음.
- Sites v64, source SHA `1ebe70b77b1f49ceab65cc2043959b9b9d608002`, build `bb945ef883915acd5a5d`.
- 실제 모바일 브라우저 조작 도구가 제공되지 않아 실기기 터치는 미검증. 자동 검사를 실제 사용자 화면 승인으로 간주하지 않음.
- 배포 후 iPhone Safari User-Agent로 `/round`, `/play` HTTP200 및 두 화면의 퍼팅 도움말·클럽 안내 확인. 배포 자산138개 SHA256과 서버 build가 모두 일치함.
