# 4개 항목 코칭 카드

2026-11-20. 사용자 요청에 따라 메인 화면은 설명 그림과 Gemini 평가/연습을 중심으로 구성했다. 실제 영상·같은사진2D 확인은 별도 선택으로 보존했다.

- 고정 항목: 준비 자세, 몸통 회전, 균형과 하체 지지, 팔과 클럽 정렬. 점수/잘한점/개선점/연습은 모델 응답이며 임의로 채우지 않는다.
- 네 그림은 서로 다른 영역을 강조하는 설명용 SVG이며 개인 관절 복원이 아니다.
- 카드/요약 75자 잘라내기 및 말줄임을 제거하고 긴 한글/영상제목을 줄바꿈한다.
- 각 항목에 관련 공개 영상 최대2개. 제목/설명과 연습 주제가 맞지 않으면 표시하지 않는다. 전체 영상 검토나 교정 효과 검증은 아니다.
- 파72 일반18홀 타수 범위 옆에 모델의 4가지 연습을 함께 제시한다. 연습만 하면 그 타수가 보장된다는 뜻은 아니다.
- 기기 프로필 entries에 ai_photo(rubric,model,dimensions)를 저장. 같은 rubric/model/conditions 이전 회차만 점수차를 표시한다. 이전 평가기준 기록이나 다른 모델 점수는 비교하지 않는다.
- PDF도 네 설명그림/모델점수/설명/연습링크를 쓴다. 실제 전송사진5장은 인쇄자료에 유지한다.

## 실제 배포/API 측정

- Site버전36/source `206ca394a9ef2cf8e05ed56c792ed718cb46082e`, build `ac9028e9f8ed42e0e0a2`.
