# 보이는 게임 카드와 기존 이용자 메인 진입

- 사용자 승인: 게임이 빠진 것처럼 보이지 않게 결과의 예상 플레이 바로 아래에 카드를 항상 표시한다.
- 첫 이용: 카드+‘예상 플레이를 마치면 게임을 시작할 수 있어요’+비활성 버튼. 전체 선택 홀 재생 완료 후 활성화.
- 결과와 재생 카드가 같은 분석의 완료 상태를 공유한다. 게임을 하고 결과로 돌아와도 다시 재생을 강제하지 않는다.
- 기존 이용: 같은 브라우저의 저장 프로필/성공한 분석 확인 후 메인에 큰 게임하기, 내 게임 스코어, 내 분석 결과 표시. 분석 재실행 없이 직접 게임 가능. 결과의 게임 카드도 즉시 활성화.
- 신규/실패 기록에는 메인 게임 바로가기가 없다. 단순 화면 표시 조건으로 로그인/유료 권한 인증은 아니다. 기기 간 동기화/친구 초대는 미구현.
- 기본 분석→예상 재생 흐름과 기존 결과/리포트/PDF/게임은 보존한다. 코스별 예상 타수 재산출과 전국 게임을 완료했다고 주장하지 않는다.
- Node180/180. 카드 상시 표시/초기 잠금, 재생 완료 후 동시 활성, 기존 이용자 홈 강조/즉시 활성, 신규/실패 조건 및 기존 회귀 검증.
- 가상 DOM 검사이며 실제 모바일 터치/레이아웃은 도구 부재로 미검증.
- Sites v68 배포 성공, source SHA `8711a1ae3ee893256148a67a57f355df8bb510aa`, build `13a6e20e1703b5b3e5c2`.
- 배포 후 홈 HTTP200/조건부 재방문 영역, 결과 카드 삽입/비활성 조건/메인 강조 코드 확인. iPhone Safari User-Agent로140개 배포 자산SHA256과 서버build 전부 일치. HTTP 확인은 실제 모바일 조작과 구분함.
