# 전체 프로세스와 최종 리포트

2026-11-20. 사용자의 전체 프로세스/최종 리포트/디자인 통합 요청을 반영했다. 기존 승인 요약, 정확한5장 수신해시, 그림코칭, 점수비교, 영상선택, 직접작은골퍼·공비행을 보존한다.

## 변경

- experience.css로 상담·요약확인·분석·4항목·타수·시뮬레이션·최종리포트의 색/카드/타이포/간격을 통일했다. 본문16px, 긴문장말줄임없음, 모바일줄바꿈.
- Gemini 사진코칭의 report.js는 예전 혼합 점수표 대신 MotionReport.mount를 사용한다. 실제 저장값으로 6개섹션: 요약/코칭2장/근거사진/홀표/홀경로. 4항목점수·잘한점·점검·연습·관련영상/사진5장/가정/토큰을 포함한다.
- 같은 코스·프로필·seed의 현재/개선 경로를 생성한다. 일반18홀예상과9홀재생합계를 구분한다. 시뮬레이션 스냅샷을 기기의 분석기록에 저장해 세션이 사라져도 재사용한다.
- 대화502/503은총28초예산에서1회재시도. 승인요약에서 코치제안을 채우도록 프롬프트를 정리했다.
- 사용자 사진/영상/상담/실제모델응답/PDF는 Git과공개Site자산에넣지않았다.
