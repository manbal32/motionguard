# 실제 PDF 출력 확인 (2026-11-20)

현재 hosted 빌드의 report.html/report.js/CSS/2D 렌더러를 사용해 실제 A4 PDF를 생성했다. 로그인된 배포 사이트 세션에서 내보낸 검증은 아니다. 원본 보고서 코드를 인라인 자산으로 렌더링하고 기존 실제 Gemini 응답과 로컬 계측을 입력했다. 상담은 기능 검증용 입력이며 PDF 첫머리에 그 사실을 명시했다. 재호출/새 진단으로 가장하지 않았다.

파일 주소 탐색은 브라우저 관리자 정책(ERR_BLOCKED_BY_ADMINISTRATOR)으로 불가했다. 정책을 변경하지 않고 파일 탐색 없는 인라인 문서 PDF 변환을 사용했다. 인라인 입력 환경에는 보고서 URL/프로필 ID 인터페이스를 제공했으며 실제 서비스 인증/업로드 검증으로 취급하지 않는다.

| 검사 | 실제 결과 |
|---|---|
| 최초 PDF | A4 7페이지. 비어 있는 이전 섹션 제목과 불필요한 부록 페이지 분리 발견 |
| 수정 후 PDF | A4 6페이지, 1,416,562bytes |
| 2D 정지 이미지 | 4개, 각 640×600 소스 이미지 포함 |
| 유튜브 추천 | 3개 개선 후보 × 2개 = 클릭 가능한 watch 링크6개 |
| 예상 링크 누락 | 0개 |
| 페이지 밖 텍스트 | 좌표 검사0개, 렌더링된 페이지 이미지에서 잘림 확인 안 됨 |
| 실제 토큰 표기 | 총7,015 포함 확인 |
| 리포트 JS 오류 | 0개 |
| 전체 페이지 이미지 | PDF를 이미지로 렌더링해6페이지 검토 |
| 로그인된 배포본의 내보내기/실제 폰 | 미검증 |
| 코스 포함 옵션 PDF | 이번 출력에서 미검증 |

빈 기존 개선/영상 섹션을 숨기고 인쇄에서 부록 강제 새 페이지와 추천 카드 여백을 정리했다. 기본 분석 PDF를7→6페이지로 줄였다. 개인 PDF·그림·좌표·원본은 GitHub나 배포 자산에 넣지 않았다.

출력 확인 중 AI 요약의 촬영 방향 분류 오류(같은 정면 영상의 장면을 혼합 시점으로 해석)를 발견했다. PDF 출력 성공과 분석 내용 정확도는 별개이며, 해당 내용 오류는 이번 레이아웃 수정으로 해결된 것이 아니다.
