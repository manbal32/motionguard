## 근본 원인 — 앞부분 프레임의 골격이 뒤집혀 있다

`samples/golf_swing.mp4` 에서 프레임별 랜드마크를 직접 뽑은 값이다.
화면 좌표이므로 **y 가 클수록 아래**다. 사람이라면 발목이 어깨보다 아래여야 한다.

| 프레임 | 어깨 y | 발목 y | 발목−어깨 | 손목 visibility |
|---|---|---|---|---|
| 14 | 0.595 | **0.498** | **−0.098** | 0.87 |
| 32 | 0.620 | **0.550** | **−0.069** | 0.74 |
| 50 | 0.490 | 0.730 | +0.240 | 0.67 |

| 194 | 0.496 | 0.735 | +0.239 | 0.79 |

**프레임 50 이전은 사람의 자세가 아니다.** 발목이 어깨 위에 있고 인물 높이가 음수다.
그런데 현재 코드는 이 프레임들을 정상 입력으로 받아 그중에서 `address` 를 고른다.
그래서 `address` 가 14 또는 39 로 잡히고, 그 프레임의 어깨폭으로
`address_shoulder_width_ratio` 를 계산하니 0.86 이라는 값이 나온다.
그 뒤의 국면·카메라 판정이 전부 이 하나에서 어긋난다.

`mockups/evidence_golfswing_f39.png` 를 열어 보면 프레임 39 는 어드레스가 아니다.

## 할 일

### 1. 해부학적 타당성 검사를 추가한다

프레임 단위로 아래를 모두 만족해야 **채택**한다.

- `발목 y − 어깨 y > 0.05` (발목이 어깨보다 충분히 아래)
- `골반 y` 가 어깨 y 와 발목 y 사이
- `어깨 y`, `골반 y`, `발목 y` 가 모두 0 초과 1 미만
- 인물 높이(`발목 y − 어깨 y`)가 **직전 채택 프레임 대비 40% 이상 급변하지 않을 것**

채택되지 않은 프레임은 국면 검출, 어드레스 선택, 어깨폭 기준값 계산에
**사용하지 않는다.** 트랙에서 지우지는 말고 `accepted: false` 로 표시한다.

### 2. 채택 구간 안에서만 국면을 고른다

`address`, `top`, `down`, `impact`, `finish` 는 전부 채택 프레임이어야 한다.
`address_shoulder_width_ratio` 와 어깨폭 최대값도 채택 프레임만으로 계산한다.

### 3. 채택률이 낮으면 측정했다고 하지 않는다

채택 프레임이 전체의 **50% 미만**이면 `meta` 에
`"usable": false` 와 사람이 읽을 수 있는 사유를 넣는다.
이 경우 각도 값을 내지 말고 `unavailable` 에 회전 채널을 넣는다.
**0 을 내는 것보다 "이 영상으로는 측정할 수 없다"가 맞다.**

### 4. 카메라 판정은 1~2 가 끝난 뒤 다시 측정한다

PR #1 에서 넣은 폭비 경계값(0.80 / 0.45)은 그대로 둔다.
입력이 고쳐지면 폭비가 달라진다. **새 폭비 실측값을 보고하라.**
그 값이 여전히 영상의 실제 촬영 방향과 맞지 않으면,
맞추려고 경계값을 조정하지 말고 그대로 보고하라. 그때 다른 방법을 쓴다.

## 통과 조건

| 항목 | 기준 |
|---|---|
| 채택 프레임 비율 | 두 샘플 모두 보고할 것 (수치 제한 없음) |
| 국면 프레임 | 5개 모두 `accepted: true` 인 프레임일 것 |
| `발목 y − 어깨 y` | 5개 국면 프레임 모두 0.05 초과 |
| `address` 손 y | `top` 손 y 보다 클 것 |
| `top → impact` | 0.15초 이상 **1.50초** 이하 — 이전 문서의 0.60초 상한은 **폐기한다** |
| `down` 위치 | `top→impact` 구간의 25%~75% |
| 기존 테스트 | `python3 -m pytest tests/ -q` 통과 |

## 제출

1. 아래를 돌린 **출력 전문**을 PR 본문에 붙인다.
2. 통과 조건 표에 실제 값을 채운다.
3. 통과하지 못한 항목은 **숨기지 말고 미통과로 적는다.** PR #1 처럼 하면 된다.

```bash
cd swing3d
python3 - <<'PY'
import video_pose, swing_track as st
for v in ("samples/golf_swing.mp4", "samples/golf_swing_portrait.mp4"):
    frames, fps = video_pose.extract(v)[:2]
    t = st.build_track(frames, fps); m = t["meta"]
    pf, f = m["phase_frames"], m["fps"]
    print(v)
    print("  usable =", m.get("usable"), "| camera =", m["camera_facing"],
          "| 폭비 =", m["address_shoulder_width_ratio"], "| unavailable =", m["unavailable"])
    print("  채택 프레임 =", m.get("accepted_frames"), "/", m.get("total_frames"))
    k = list(pf)
    for a, b in zip(k, k[1:]):
        print(f"  {a:8s}->{b:8s} {pf[a]:4d}->{pf[b]:4d}  {(pf[b]-pf[a])/f:5.2f}s")
PY
```
