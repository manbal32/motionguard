# 인수인계 · 새 대화에서 이 프로젝트를 이어받을 때

새 세션(어느 도구든)은 이 파일부터 읽는다. 순서대로 읽으면 맥락이 복원된다.

| 파일 | 무엇 |
|---|---|
| `PRODUCT_FLOW.md` | 제품의 진실. 흐름 · 결함 사전 · 토큰 추정 · 과장 상한 |
| `CODEX_NEXT.md` | 현재 유효한 작업 지시 6단계 + 스크린샷 게이트 + 디자인 규칙 |
| `REVIEW_01.md` | 마지막 검토. 미해결 결함 4건 |
| `mockups/DESIGN.md` | 디자인 방향과 판단 기준 |
| `WORK_ORDER.md` | 품질 기준 · 하지 말 것 · 보고 형식 (계속 유효) |

## 역할 분담

- **사람(동원)** — 방향 결정. 화면을 보고 "이게 맞다/아니다" 를 판단한다.
- **검토자(대화하는 AI)** — 스펙을 쓰고, 결과를 진단하고, 지시서를 저장소에 커밋한다.
  코드를 직접 쓰지 않는다. 토큰을 구현에 쓰지 않는다.
- **Codex** — 구현. 지시서를 읽고 만들고 스크린샷을 찍어 커밋한다.

**검토자와 구현자를 같은 도구로 묶지 마라.** 구현자가 지시서의 오류를 그대로
구현하는 일이 실제로 일어났다 — `REVIEW_01.md` 1번이 그 사례다. 공식은 지시서대로
맞았지만 결과가 물리적으로 불가능했고, 구현자는 질문하지 않았다. 다른 눈이 필요하다.

## 제품 한 줄

사람은 12° 차이를 못 본다. 2.5배로 과장하면 본다. **과장이 제품이다.**
3D/2D 는 매체일 뿐이다. 현재 메인은 2D 나란히 비교, 3D 는 카메라 각도용 보조다.

## 지금 상태

- 좌표 추출 · 9채널 트랙 · 국면 검출 · 크롭 · 리포트 · 판정 UI — 동작한다.
- 2D 나란히 비교 — 1차 구현됨. `REVIEW_01.md` 의 4건이 미해결이다.
- Gemini 연동 — 아직 없다. `findings/golf1.json` 고정 파일로 개발 중이다.

## 검토자가 직접 쥐고 있는 것 (Codex 에 넘기지 않음)

- `swing_track.py` 의 다운스윙/임팩트 몸통·골반 `0.0°` 문제.
  원인 후보는 `max(0.0, …)` 클램프다. 검토자가 심은 것이고 검토자가 본다.
- 채널별 신뢰도, visibility 하한 `0.5 → 0.3`.

## 환경

- 개발 머신은 맥(Apple Silicon). 회사 Windows 는 읽기 전용으로만 쓴다.
  회사 프록시가 CDN 과 Google Storage 를 막는다 — 그래서 three.js 와 모델이
  저장소에 들어있다. **그대로 둔다.** 오프라인 동작은 제품의 장점이다.
- 사업용 코드를 업무용 PC 에서 돌리지 않는다.

## 보안

- `.env` · `local-data/` · `.venv/` · `*.mp4` · `*.mov` · `outputs/` · `__pycache__/` 커밋 금지.
- API 키는 채팅에 쓰지 않는다. 로컬 파일에만 둔다.
- 커밋 전 `git diff --cached` 로 키 패턴을 확인한다.
- SMPL / SMPL-X / GVHMR 사용 금지 — 비영리 연구 라이선스다. 이것은 사업이다.
- 원본 영상은 로컬에만 둔다.
