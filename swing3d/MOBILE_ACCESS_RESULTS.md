# 공개 모바일 접속 및 실제 서버 검증 (2026-11-20)

사이트 공개 설정 유지. 실제 iPhone User-Agent 비인증 HTTP 요청에서 홈/index/course?demo=1/report 및 핵심 파일·상태11개 모두200. Android User-Agent로 HTML/JS/CSS/wasm/task43개 모두200/실패0. 실제 Safari/Chrome 엔진이나 물리적 휴대폰 테스트를 의미하지 않는다. 첫 외부 HTTP 진단에는403/1010도 관측됐고 현재 성공만으로 사용자의 네트워크 오류 원인이 확정되지는 않는다.

실제 배포 상담 API에 합성 테스트 고민을 보내 두 턴200을 확인했다. 그 다음 summary는502로 재현됐다. 모델에게 요약을 요청하는 마지막 사용자 지시와 네 문자열 필수 JSON 스키마를 추가했다. 수정 배포 후 실제 대화200/1.07초/217토큰,2차200/1.18초/414토큰,요약200/0.75초/493토큰을 확인했다. 상담 내용은 합성 테스트이며 개인 상담 원문은 커밋하지 않는다. 모델의 코칭 내용 정확도까지 보증한 검사가 아니다.

앱 HTML/JS/CSS 서비스워커를 network-first/offline fallback으로 변경해 캐시된 이전 버전 우선 반환 문제를 줄였다. 기존 서비스워커가 남은 브라우저는 업데이트/재접속이 필요할 수 있다.

Node49개 통과/실패0,Worker 및 SW 문법 검사 통과. 이번에 추가한 요약 테스트는 마지막 지시와 필수 스키마 및 실제 응답 처리 검증이다. 앞선 생성 핸들러 테스트로 대화 이력·즉시 요약화면 전환·실패 재시도 검증을 유지한다.

현재 관리 환경은 remote_desktop enabled지만 callable cua_repl/browser/open_in_codex 도구가 없다. Sites 지침에 따라 임의 브라우저 QA 우회를 하지 않았다. 물리 iPhone/Android 터치,파일 선택,영상 디코딩/MediaPipe 실행,실제 분석 결과 화면,지도 재생 시각 검증,모바일 PDF 저장은 이번 수정에서 미검증이다. 기존 로컬 PDF 출력/로직 테스트를 실제 휴대폰 E2E 통과로 간주하지 않는다. 모든 시나리오 통과라고 보고하지 않는다.
