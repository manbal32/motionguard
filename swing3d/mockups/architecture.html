사람

요약을 먼저 되돌려준다

대화를 고민 / 연습 목표 / 사용자가 생각한 원인으로 정리해 보여준다. 확인 없이 최종 판정으로 넘어가지 않는다.

수정 · 승인

사용자가 고치거나 승인한다. 승인된 값은 종합 분석 · 화면 · 리포트에 같은 값으로 전파되며 재요약이 덮어쓰지 않는다.

계측 트랙 ─┬─ 상담 트랙
승인 요약 + 국면 전후 ±5표본(55×9) + 교본값 + 신뢰도 · ≈1,500 입력 토큰

결함 사전 — 선택지 제한

판정 가능한 결함 8종만 제시한다. 캐스팅 · 골반 미회전 · 어깨 회전 부족 · 조기 열림 · 스웨이 · 상체 들림 · 무릎 펴짐 · 체중 미이동. 각 결함은 채널과 구간에 묶여 있다.

입력 분리

conversation_summary · measured_evidence · reference_data · confidence 를 섞지 않고 따로 넘긴다. 자기보고와 실측을 모델이 구분할 수 있어야 한다.

계약 검증

검증 통과분 + 측정 트랙 + 교본 트랙
07

행동

로컬

스탠스 보존 아바타

오른쪽 아바타는 교본 복제가 아니라 그 사용자의 해당 프레임 랜드마크에서 출발한다. 발 위치 · 어깨 높이 · 척추 전경사를 1.0×에서 유지한다.

국소 과장

표시값 = 교본 + (측정 − 교본) × 배율. 전체가 아니라 차이만, 그중에서도 선택한 채널만 증폭한다. 상한 3.0, 측정값의 부호를 넘지 않도록 0에 점근 압축한다.

잘한 점은 과장하지 않는다

긍정은 무채색 ‘유지’ 라벨로 해당 프레임만 표시한다. 경고색 주황은 개선점에만 쓴다 — 경고와 칭찬이 같은 색을 쓰면 안 된다.

동기화 2D 비교

왼쪽 원본 영상 + 실측 관절, 오른쪽 같은 프레임의 2D 사람형 아바타. 재생 · 구간 반복 · 0.5× · 1프레임 이동을 공유한다.

3D 재구성 보조

정면 촬영은 스윙 플레인이 보이지 않는다. 그때만 다운 더 라인으로 돌려 본다. 깊이는 측정값이 아니라 추정이라고 명시한다.

설계 근거

에이전트 설계에서 의도적으로 선택한 다섯 가지.

01

지각과 추론의 분리

LLM 이 영상을 직접 보지 않는다. 지각은 결정론적 모델이 맡고 LLM 은 그 출력인 수치만 읽는다. 토큰이 줄고, 같은 영상에 같은 좌표가 나오므로 판정이 재현된다.

02

사람이 개입하는 두 지점

증상 수집은 대화로, 그 요약은 승인으로 받는다. 에이전트가 자기 요약을 스스로 입력에 넣지 않는다. 오해가 최종 판정까지 번지기 전에 사람이 끊을 수 있다.

03

출력 공간의 제약

결함 사전 8종으로 선택지를 좁히고, 스키마와 실측 트랙으로 두 번 검증한다. 자유 서술을 받지 않으므로 “그럴듯한 코칭”이 근거 없이 화면을 움직이지 못한다.

04

행동과 근거의 결합

채널과 구간을 가진 결함만 과장 렌더링까지 간다. 에이전트의 행동 범위가 자기 측정값의 범위를 넘지 못하도록 구조로 막았다.

05

로컬 우선

외부로 나가는 것은 대화 텍스트와 계측 요약뿐이고 원본 영상은 로컬에 남는다. 모델과 렌더링 라이브러리를 저장소에 포함해 네트워크 없이도 지각 · 표상 · 행동이 돈다.
