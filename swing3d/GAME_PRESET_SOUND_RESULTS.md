- 힘100%·기본 날씨의 게임용 기준값. 개인 스윙 측정값은 아니다. 힘 비율·비퍼터 작은 거리편차·기온·바람·비를 반영한다. 실제 슬라이스 스핀을 계산하지는 않는다.
- 새 샷/새 홀/새 라운드 기본 힘100%. 사용자 조절 가능. 이미 저장된 현재 힘은 복구 시 보존한다.
- 새 진입은 거리/코스 선택. 테스트 주소 `/play`는 유효한 진행 라운드를 자동 이어한다. 저장 프리셋 보존/이전 저장은 남성으로 이전.
- 홀인 시 결과 이름과 영문 태그를 크게 표시하며 진입 모션, 로컬3음 효과음 제공. 기브/마무리는 무음. 저장된 완료 화면 재진입이나 단순 렌더에서 소리를 반복하지 않는다.
- 시작/샷/소리 버튼 제스처에서 오디오를 열고, 브라우저 미지원/차단 시 무음으로 정상 플레이. 소리 끄기 제공.
- Node172/172. 남녀 실제 UI핸들러 각각18홀 완주, 거리/날씨/힘/저장/안내 일치, 결과 배지와3음·뮤트·재진입 무음 검사.
- 실제 모바일 터치와 소리 청취는 환경에 브라우저 조작 도구가 없어 미검증. 가상 DOM/Web Audio API 검사를 실기기 승인으로 보고하지 않음.
- Sites v65 배포 성공, source SHA `9b42207b7092c895cbf460698a44b1c21eb85066`, build `85a322c6875c7ed9e8f5`.
- 배포 후 iPhone Safari User-Agent로 `/round`와 `/play` HTTP200 및 남녀 선택/100% 힘/소리 모듈/결과 태그 포함 확인. 서버 build와139개 배포 자산SHA256이 모두 일치함. HTTP 확인은 실제 모바일 소리 청취/화면 검증과 구분함.
