# Gemini 공통 결과 기반 전체 시연 (2026-11-20)

## 최종 흐름

영상첨부→모션가드코치 자유대화→고민/목표 요약수정·승인→대표사진5장+승인요약→단일 Gemini 사진응답 저장→점수/개선점/현재·개선18홀범위→항목별영상/정지2D/유튜브→골프장검색/홀별골퍼·공비행→같은분석값 PDF.

새 응답에 assessment_score(value/basis/confidence), score_estimate(status/current/improved/basis/assumptions/confidence)를 추가한다. 숫자범위 검증 실패/필드누락/근거부족은 insufficient/null이며 고정90이나 로컬동작점수로 대체하지 않는다. 실제원본/좌표는외부전송하지않고 승인요약+JPEG5장만전송한다. 사진점수는측정정확도검증된수치가아닌모델평가다.

MotionAIResult가저장된같은분석객체를읽으며결과/PDF/코스프로필이그값을참조한다. 사진분석모드의시나리오프로필은로컬점수/계측유무에의존하지않는다. 기존분석은응답에타수가없으면미제공으로표시하고재분석이필요하다.

코스의작은골퍼/샷/퍼팅은모델타수범위를참고해96개이내seed의재생후보를고르는시각화다. 선택된코스지원홀수에비례한범위중앙을참고하며,매홀샷+퍼팅합계는실제재생한숫자를유지한다. 타수총합을임의로덧붙이지않는다. 달성가능한후보가없으면가장가까운재생을쓰며범위일치를보장하지않는다. 재생합계는선택된9홀등홀수기준으로표시하며Gemini18홀참고범위와구분한다. 범위미확보시기본가정재생은가능하나AI예측인것처럼보여주지않는다. 내부샷편차모델은연출용으로남으며더이상새로운예상타수를사용자에게산출하지않는다.

PDF는사진분석영역과코스부록에같은AI범위/근거를포함한다. 코스부록의샷합계는재생용으로명명하며기존별도32회가정평균을AI범위로대체하지않는다. 기존로컬참고계측부록은기기에서측정된정보로남긴다.

## 검증 실측

- Node57개 통과/실패0. 새검증: 범위보존/역전범위거절/누락시미추정/공유프로필연결/재생샷합계일치/사진점수별도보존.
- Worker/client JS 문법 및 portable hosted 빌드 통과.
- 실제배포엔드포인트에이전에사용자가제공한영상의기존대표사진5장과테스트고민을전송했다. 새영상의국면선택성공검증은아니다.
- 첫실제시도502: 응답미완료/파싱실패 일반오류였고정확한세부원인은미기록. 출력한도를5000→8000으로늘리고미완료/형식/timeout오류를구분한후재시도200성공.
- 성공응답: gemini-3.5-flash-lite,5.54초,입력6244+출력1338=7582토큰(캐시4025포함),사진평가78점,현재92–98/개선88–94타,근거항목5개. 개인사진/고민원문/원본응답은Git제외.
- 이수치는실제골프실력/스코어의정확도검증이아니다. 모델의근거에퍼팅/숏게임/실전미스미확인과조건부개선을명시했다.
- 실제모바일터치/새영상업로드/전체PDF실출력은이번수정에서미검증. 기존PDF실측을새버전통과로재사용하지않는다. 관리환경에지원cua/browser조작도구가없어Sites지침대로임의브라우저QA우회없이코드/API검증만수행했다.
- 다른골프장전체홀자동인식과지도데이터범위의기존한계는변경되지않았다. 모든코스전체홀지원완료로주장하지않는다.

## 재현

```sh
cd swing3d/hosted
python scripts/build_server.py
node --test tests/*.test.mjs
node --input-type=module --check < dist/server/index.js
```

GEMINI_API_KEY는Sites서버비밀값. API /api/coaching/visual에allow_images:true,samples5개,summary를전송한다. 응답을기기리포트에저장하고모든소비자가visual_analysis.analysis를읽는다. 개인파일을Git/배포assets에넣지않는다.
