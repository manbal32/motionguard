# 원본 영상 + 2D 전체 구성 — 2026-11-20

최신 사용자 요청: 영상에도 부위 표시를 제공하면서 명확한 2D 비교를 유지한다. 분석이 중심이며 코스/작은 골퍼는 보조 기능이다.

## 구성과 구현

- **같은 분석·같은 순간:** 원본 영상에는 선택된 부위의 실측 표시만 얹고 영상 픽셀/자세를 변형하지 않는다. 교정 방향은 2D에 분리한다. 모바일은 ‘내 영상 / 2D’ 전환, PC는 나란히. 재생 위치와 반복 구간은 공유한다.
- 기존 전체 골격 표시 대신 선택 부위의 원/연결선. 필요한 관절 중 가려진/낮은 가시성이 있으면 표시를 생략한다. 표시 켜기/끄기 지원.
- 결과 카드도 원본이 있으면 같은 프레임의 원본+2D로 구성. 원본 디코드 후 2D를 같은 프레임으로 그리며, 한 번에 하나의 구간을 반복한다. 부위 확대는 원본과 2D에 적용한다.
- 원본 없는 CSV/새로고침은 원본이 없다고 안내하고 2D 유지. 이전 영상을 다른 CSV에 붙이지 않는다. 살아 있는 원본이 없는 대표장면은 사진이라고 표시하고 동작 반복은 2D로 전환한다.
- **PDF:** 같은 장면의 표시된 원본(있을 때)과 2D 가이드를 묶는다. 세션에 원본 장면이 없으면 2D/원본 미존재 안내. 기존 분석 중심 PDF/코스 선택 포함 정책 유지.
- 원본은 로컬 메모리에서만 디코드. 보고서에 필요한 항목별 대표 JPEG만 같은 탭 sessionStorage에 보관. 파일 변경/프로필 삭제 시 삭제. 좌표·프레임 ID가 일치한 캐시만 사용. 외부 LLM 전송/동의 범위 불변.
- 2D는 영상의 원래 가로세로 비율을 반영해 구성. 영상이 없는 CSV는 기존 좌표 재구성 유지. 빠른 탐색 후 오래된 영상 콜백이 들어오면 현재 위치를 사용하도록 방어.

## 실제 검증과 남은 한계

|---|---|---|

| 스타일 | 1개 통과 | 통과 |
| CSV 결과/가이드 | 모바일·PC 카드4개, 긍정 픽셀 일치, 반복/정지/확대/크게보기, 원본 없는 경우 2D 유지 | 통과 |

| 원본+2D 독립 시연 | PC 나란히/모바일320·390 전환, 같은 프레임102, 표시 토글, JS오류0 | 통과 |

| 정상 원본 영상 분석 E2E | 정상 스윙으로 통과한 원본이 현재 없음. CSV를 다른 영상에 결합하지 않음 | 미검증 |

실제 영상 기술 시연에는 기존 golf_swing.mp4와 **그 영상에서 추출한 원본 공간 좌표**를 사용했다. 이 영상의 기존 usable=false/no_swing 판정은 변경하지 않았다. 이 영상에 CSV의 긍정/개선점이나 교정값을 붙이지 않았다. 프레임 동기화/부위 표시를 확인한 것이 정상 스윙 판정 성공은 아니다.

실제 영상 시연/한장 PDF는 **로컬 전달 산출물**이며 원본 영상·원본 사진은 커밋하지 않는다. `mockups/dual-*`에는 숫자/로그만 보관한다. 저장소의 캡처·PDF는 공개 샘플 CSV 재구성만 포함한다. 기존 단계11 미통과/네이버 지도 자동화·지도 권한·물리 모델 검증의 한계는 유지한다.
