# 실제 리포트 파일 다운로드

2026-11-20. 사용자 요청은 리포트 버튼이 실제로 동작하고 파일을 저장할 수 있게 하는 것이다. 홀별 데이터는 리포트에서 제외하고 모델명 표시를 숨긴다.

## 최종 동작

- 결과의 리포트 보기는 같은 문서에서 즉시 열린다. 미디어ready/다른페이지/원본영상/서버분석에의존하지않는다. 일반href는스크립트실패시fallback으로유지한다.
- 리포트내PDF다운로드/새창PDF열기/지원기기파일공유제공. 4쪽이준비되면실제Blob URL과download파일명을설정한다. window.print에의존하지않는다. 준비/완료/실패/재시도를화면표시한다.
- 현재저장분석의요약/4개코칭/그림/사진5장/관련영상/근거·사용량만포함. 홀별표·경로없음. 사진밑과리포트에Gemini/모델명없음. 내부모델메타데이터는비교·감사를위해보존한다.
- html2canvas1.4.1(MIT)을자체assets로동봉,6장면이아닌4쪽렌더를순차캡처하고PDF1.4 JPEG페이지/클릭가능HTTPS링크로구성한다. 이미지기반PDF이므로텍스트복사/검색형PDF는아니다.
- 사진/리포트는서버나제3자서비스에전송하지않는다. 추가Gemini호출/요금없음.
- report=latest는같은브라우저의최근세션/기기프로필기록을읽는다. 기록이없으면설명표시,가짜리포트/재분석을시작하지않는다.
