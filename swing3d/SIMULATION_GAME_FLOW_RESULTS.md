# 최종 시뮬레이션 안의 직접 플레이

사용자 정정: 서비스 처음부터 게임을 제공하지 않는다. 사용자의 분석 결과 뒤 최종 시뮬레이션에서 게임한다. 별도 링크는 개발 확인용이다.

- 전체 앱 첫 화면과 지도 화면의 게임 링크 제거.
- 분석 결과의 기본 리베라 ‘시뮬레이션’ 클릭→같은 문서 안에 직접 플레이 패널.
- 패널 내부 `/round`에서 두 코스 선택→18홀 게임. 닫으면 기존 분석 결과 DOM으로 돌아감.
- 현재·개선 후 자동 재생은 별도 버튼으로 유지. 다른 골프장 검색 재생/PDF 보존.
- `/play`는 ‘게임 기능 테스트’ 안내를 붙여 별도 유지하고 서비스 UI에서는 연결하지 않음. 인증 전용 URL은 아님.
- 동일 원본 게임 HTML/JS/36개 공개 홀 그림/날씨/로컬 라운드 저장을 사용함.
- Node162/162. 결과 렌더링부터 게임 열기·닫기·기존 자동 재생 전환까지 가상 DOM 핸들러 검사. 첫 화면 링크 제거·테스트/임베드 빌드 구분 검사.
- 실제 브라우저/모바일 조작 도구가 없어 실기기 터치와 iframe 높이/레이아웃은 미검증.
- Sites v63 배포 성공, SHA `f14c5d8edfce53adef4d0346b03b885cfdaa61e7`, build `4173b420fe159f65947d`.
- 배포 후 iPhone Safari User-Agent로 `/`, `/map`, `/round`, `/play` HTTP 200 확인. 서비스 첫 화면·지도·임베드에 게임 테스트 진입 링크 없음, `/play` 테스트 안내 확인. 임베드 응답에 X-Frame-Options DENY/CSP 차단 헤더 없음. 배포 자산138개 SHA256 전부 일치. HTTP 검증은 실제 화면 검증을 대체하지 않음.
