# 첫 이용과 재방문 흐름

최신 요청: 분석 서비스/예상 플레이를 먼저 제공하고, 직접 게임은 그 뒤에 한다. 기존 서비스 이용자는 별도 재접속 때 게임과 스코어로 바로 갈 수 있다. 친구 초대는 향후 확장한다.

- 첫 이용: 업로드→상담→요약 승인→분석 결과→코스 선택→홀별 예상 플레이→게임하기.
- 시뮬레이션 버튼은 게임 iframe을 즉시 열지 않는다. 작은 골퍼/공의 예상 재생을 열고 현재·개선 후18홀 범위를 함께 표시한다. 전체 홀 자동 이어 재생/수동 홀 선택/현재·개선 후/결과 복귀 보존.
- 한 모드에서 선택한 모든 홀을 재생 완료하면 리베라게임 버튼을 표시한다. 마지막 홀로 건너뛰기만 해서는 열리지 않는다. 같은 페이지에서 완료한 결과/코스는 게임에서 돌아와도 유지된다.
- 재방문: 같은 브라우저의 프로필과 성공한 Gemini 분석 리포트를 확인하면 홈에 내 결과/게임하기/내 게임 스코어 표시. 저장된 결과/점수카드로 직접 이동하며 분석을 다시 요구하지 않는다. 게임 기록이 없으면 없다고 안내한다.
- UI 진입 조건이며 로그인/유료 권한 차단 기능은 아니다. 계정/기기 간 동기화/친구 초대와 친구 샷 공유는 미구현.
- 코스별 예측값을 새로 요청하는 기능은 미완성이다. 현재는 사진·상담 분석에서 받은 범위를 선택 코스의 가상 재생에 사용한다. 게임 조작의 실타수와 AI 참고 추정을 구분한다.
- 서비스 이용 중의 기존 분석/영상/결과/리포트/PDF, 독립 테스트와 게임 프리셋/날씨/소리/쉬운 퍼팅은 유지한다.
- Node178/178: 신규/실패/성공 분석의 진입 조건, 예상 재생 전체 완료 후 게임, 값/결과 복귀, 스코어 직행/없음 처리 및 기존 전체 회귀. 가상 DOM 검사이며 실제 모바일 터치/화면은 미검증.
- Sites v67 배포 성공, source SHA `865a9606bdd4f5d0e0a391c187a9a8bcf3207736`, build `0997b046e74faf15d1f8`.
- 배포 후 iPhone Safari User-Agent로 홈 HTTP200/신규 바로가기 숨김/기본 예상 재생/후속 및 재방문 접근 모듈 확인. 서버 build와140개 배포 자산SHA256이 전부 일치. 실제 브라우저 조작은 별도 미검증.
