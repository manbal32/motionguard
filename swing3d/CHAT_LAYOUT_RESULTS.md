# 대화 잘림 및 첫 화면 동선 수정

사용자 iPhone 캡처에서 뷰포트 고정 flex 화면의 업로드/시연 버튼과 입력창이 대화 높이를 압축하고 말풍선이 잘리는 결함을 확인했다. 대화 컨테이너 overflow:hidden과 남은 높이에 맞춰 축소하는 구성을 자연 페이지 흐름으로 변경했다. 말풍선은 flex-shrink0/줄바꿈 유지,전체 이력 스크롤,입력창 sticky로 변경했다. 새 메시지를 화면에 가져온다.

홈 샘플 체험 버튼,CSV 메뉴,골프장 시연 진입 및 기술 배너 제거. CSV 내부 처리 코드는 기존 기능 보존을 위해 남기되 노출하지 않는다. 골프장 현재/개선 비교는 분석 결과의 기존 진입에서 접근한다. 기존 상담/승인/사진분석/영상/정지2D/유튜브/PDF 유지.

빌드/JS문법 통과,Node49개 통과. 실제 모바일 캡처 재검증은 이 환경에 지원 브라우저 조작 도구가 없어 미검증이다. 사용자 원본 캡처나 상담 데이터는 커밋하지 않았다.
