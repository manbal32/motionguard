# 여러 골프장 지도 검색 실제 검증 — 2026-11-21

수정전에도검색자체는각각200/후보40개였다. 남서울/88은고정검색어의상위20개에사용할지도가없었다. 같은골프장이름+코스맵/코스공략도검색에서실제지도가발견되어discover에3검색병렬·중복제거·교차배치를적용했다. 단순거리표를지도라했던골드사례때문에선별응답에single-hole/overview분류를요구하고표유형은거부한다. API클라이언트indices형식은유지한다.
