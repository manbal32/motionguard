# OpenStreetMap data

`course-catalog.json` and `course-snapshots/*.json` are derived from OpenStreetMap contributors, retrieved on 2026-11-20 via Overpass API and the OpenStreetMap map API.

The catalog is a source snapshot, not an official list of current operating golf courses. Availability, names, course/tee grouping and hole coverage may be incomplete. Fairway polygons are not automatically numbered holes. Source object IDs are retained for provenance.

## NAVER-discovered map source metadata

map-sources.json contains public source URLs, publication dates and coverage metadata only. Source images are not included or relicensed. NAVER/blog/CDN availability does not confer reproduction rights. Source dates are 2023-09-01 (Rivera overview) and 2022-05-26 (Korea Challenge hole9). Gold unnumbered material was rejected.
